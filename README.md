# Chocolate Sales Analysis Dashboard

## Project Overview
An interactive Chocolate Sales Dashboard developed using Microsoft Excel, Power Pivot, PivotTables, PivotCharts, and slicers to analyse sales performance and generate business insights.

## Objectives
- Analyse total revenue, profit, quantity sold, and profit margin.
- Compare product categories and brands.
- Evaluate store and customer performance.
- Identify monthly sales trends.
- Understand purchasing behaviour across customer segments.

## Tools Used
- Microsoft Excel
- Power Query
- Power Pivot
- PivotTables and PivotCharts
- DAX Measures
- Interactive Slicers

## Data Model
The project uses five related tables:
- Sales — Fact Table
- Products — Dimension Table
- Customers — Dimension Table
- Stores — Dimension Table
- Calendar — Dimension Table

## Dashboard Features
- KPI cards
- Revenue and profit analysis
- Product and brand performance
- Monthly sales trends
- Brand-wise profit in each country
- Profitable chocolate brands
- Customer segmentation
- Interactive filters for Year, Country, Category, Brand, Gender, and Loyalty Membership

## Business Requirements
The dashboard explores multiple business questions related to revenue, profitability, product performance, discount analysis, store performance, customer behaviour, and monthly trends.

## How to Use
Download the Excel workbook and open it in Microsoft Excel desktop to explore the PivotTables, PivotCharts, and slicers.
